# OPPER · Organic Soap & Skincare — Brand Portfolio

> **Pure by nature. Made with care.**  
> Handmade organic soap crafted with goat milk, saffron, ayurvedic herbs, and nourishing oils. Natural, chemical-free skincare, made in small batches.

---

## 🌿 Overview

**OPPER** is an artisanal organic soap and skincare brand founded by **Geetha**. Each bar represents a commitment to pure, restorative, and chemical-free skin wellness.

This repository hosts the official brand portfolio and interactive showcase landing page.

---

## ✨ Features & Highlights

- **Artisanal Design System:** Warm earth tones, gold accents (`#B8892B`), and elegant serif typography (*Cormorant Garamond* & *Jost*).
- **Interactive Product Showcase:** Detailed tabs and cards highlighting the key ingredients:
  - 🥛 Fresh Goat Milk
  - 🌸 Kashmiri Saffron
  - 🌿 Ayurvedic Herbs & Extracts
  - 🥥 Pure Cold-Pressed Oils
- **Image Lightbox & Zoom:** High-resolution product visual gallery with interactive modal previews.
- **Scroll Progress & Micro-Interactions:** Custom reading progress indicator, animated marquee, and card hover transformations.
- **Dark & Light Mode Support:** Automatic detection with graceful styling across system color preferences.
- **Zero External Dependencies:** Built as a self-contained, lightning-fast static webpage with inline assets and Google Fonts.

## 🚀 Quick Start / Local Preview

To view the portfolio locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/TarunScript/opper-portfolio.git
   cd opper-portfolio
   ```

2. Open `index.html` in your web browser:
   - **macOS:**
     ```bash
     open index.html
     ```
   - **Linux:**
     ```bash
     xdg-open index.html
     ```
   - **Windows:**
     ```cmd
     start index.html
     ```

---

## 🌐 Deploy to GitHub Pages

To make the portfolio live on the web:
1. Navigate to **Settings** > **Pages** in this GitHub repository.
2. Under **Build and deployment** > **Branch**, select `main` branch and `/ (root)` folder.
3. Click **Save**. Your site will be published at:  
   `https://tarunscript.github.io/opper-portfolio/`
